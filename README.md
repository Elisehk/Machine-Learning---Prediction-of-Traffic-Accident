# Machine-Learning---Prediction-of-Traffic-Accident
Prediction of Traffic Accident with Machine Learning

Objectives:
1.To practise machine learning (ML) with data analysis on traffic accidents
2.To compare the performance of ML models
3.To apply the model to predict real-life scenario: risk of injury on a road

Contents:
Data Preprocessing and Feature Engineering
Machine Learning Methodology
Models: Logistic Regression, Random Forest, Histogram-based Gradient Boosting Classification Tree (HGB)
Tuning Method
Analysis and Evaluation on Models
Performance of Models
Model Comparison
Challenges, Limitations and Future Work
Application
Conclusion & Insight
